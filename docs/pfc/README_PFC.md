# Documentation PFC — SupMtiShop

Ce dossier applique le guide de démarrage PFC au projet SupMtiShop.

## Fichiers importants

- `Rapport_PFC_SupMtiShop.md` : rapport complet en texte Markdown.
- `Cahier_des_charges.md` : besoins fonctionnels et contraintes.
- `Planification.md` : plan du projet par semaines.
- `Tests_validation.md` : plan de tests client/admin.
- `Preparation_soutenance.md` : plan de présentation et questions possibles.
- `uml/` : diagrammes PlantUML.
- `Guide_PFC_reference.pdf` : guide original fourni.

## Comment utiliser

1. Ouvrir ces fichiers dans VS Code.
2. Copier le contenu dans Word si le professeur demande un rapport Word/PDF.
3. Ouvrir les fichiers `.puml` avec PlantUML pour générer les diagrammes.
4. Utiliser `Preparation_soutenance.md` pour préparer les slides.
