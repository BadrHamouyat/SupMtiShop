## Pitch court

SupMtiShop est une application web e-commerce qui permet aux clients de consulter des produits, créer un compte, ajouter au panier, passer une commande, payer et donner un avis. L’administrateur peut gérer les produits, images, catégories, commandes, utilisateurs et consulter les statistiques de vente.

## Questions fréquentes

- Pourquoi Node.js ? Réponse : rapide, simple et adapté aux applications web.
- Pourquoi JSON ? Réponse : choix simple pour démonstration locale, améliorable vers MySQL.
- Comment gérer la sécurité ? Réponse : mots de passe hashés avec bcryptjs et sessions.
- Comment gérer les images ? Réponse : upload avec Multer vers `public/images/uploads`.
